报告严格区分：已经完成的正式机器结果、只用于过程检查的结果，以及尚未执行的未来任务设计。NT-v2 500M目前是下一版必加基线，尚无本项目正式成绩；64K只训练到第569次参数更新，不能视为已完成模型。

v2.3补齐了Stage B数据从原始基因组到实际训练抽样的完整链路：

- 纠正原有基因组版本划分数字：258个原始版本预设为训练192、验证35、测试候选31；筛选后实际贡献Stage B片段的是180、29和29个版本，三组版本交叉数为0；
- 用通俗语言说明GFF3区域构建、4K/8K/16K长度选择、配额、边界、未知碱基和低复杂度过滤、字节编码及为什么300亿参考预算最终得到412.43亿碱基；
- 逐类给出7种区域的全部/训练片段数，以及按真实旧读取器计算的step14000和step17000预计抽取次数；
- 明确区分“7类区域几乎肯定都被大量抽到”与“旧日志没有逐区域真实抽取计数”，不把数学期望写成历史实测；
- 没有新增或重跑正式测试，历史模型、checkpoint和性能数字均未改写。

v2.2纠正并补充了Stage B数据分片与抽样说明：

- 理论上可以把约41.24 GB编码写成单个文件；拆成42个分片是读取、校验和局部恢复的工程选择，不是物理限制或生物学分组；
- 完整分片按约10亿个碱基装满，而不是按片段条数装满；4K/8K/16K片段长度不同，因此片段数不相同；
- 如实披露旧读取器使用“分片全部片段数”加权后再过滤训练组，导致单条训练片段相对抽样权重约为理想均匀值的0.980–1.067倍；验证和测试片段没有进入参数更新；
- 没有新增或重跑正式测试，历史训练和性能数字均未改写。

v2.1在v2.0证据内容不变的基础上，重点改写了阅读方式：

- 数据抽样、模型结构、训练停止、下游比较、未来任务和统计规则均改为“先讲实际做法，再保留技术名”；
- 没有新增或重跑正式测试，所有性能数字与v2.0一致。
